# Third-Party Licenses

## Complete build: templates 01–20

No external runtime libraries, icon packages, stock-photo bundles, font packages or copied commercial-template assets are included in this build.

The collection uses only:

- HTML5 browser APIs.
- CSS3 / CSS Custom Properties.
- Vanilla JavaScript ES6+.
- PHP standard-library functionality.
- Original SVG illustrations created specifically for the templates.
- Render-derived showroom previews generated from this collection itself.
- System font stacks and generic font families.

Accordingly, there are no third-party runtime dependencies to enumerate in the final 20-template build.

If future revisions introduce Anime.js, Splide.js, Tabler Icons or another dependency, its exact name, version, author, official URL and MIT-compatible license must be documented here before distribution.
